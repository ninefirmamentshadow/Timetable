# CLAUDE.md

Timetable — a mobile-first, offline booking scheduler for an independent outcall
operator. Appointments, recurring availability, overlap and travel-buffer
conflict warnings, and an earned-vs-projected earnings view. No permissions, no
network; all data is local.

See `AGENTS.md` for execution rules, the security posture (no permissions,
alias-first, local-only), and the protected-data boundary. See `README.md` for
the feature surface and build.

Sovereign-Ops is the umbrella source of truth; this repository is the standalone
home of the app.
