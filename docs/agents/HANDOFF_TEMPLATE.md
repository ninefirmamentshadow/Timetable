# Handoff / continuation template

Copy into the PR description, handoff doc, or final report. Keep it short. Label every line as fact (F), inference (I), or speculation (S) where it isn't obvious. No private data, no secrets.

```
Date (with zone):
Agent / tool:
Task (as requested):
Branch / commit (full SHA) / pushed?:
PR:

Status labels (only those with evidence): implemented | compiled | tested | device-tested | signed | delivered | merged | published

Tests run (exact commands → result):
Build / CI (result, or "not run: reason"):
Not done / deliberately skipped (why):
Blockers / missing access (precise; no credentials):
Owner decisions needed (only consequential ones):
Next step for the next agent:
```

Definition of done and the rules behind this template: root `AGENTS.md`.
