# CLAUDE.md

Timetable — a mobile-first, offline booking scheduler for an independent outcall
operator. Appointments, recurring availability, overlap and travel-buffer
conflict warnings, and an earned-vs-projected earnings view. No network; all data
is local; the only permissions are the owner-approved reminder and app-lock ones.

See `AGENTS.md` for execution rules, the security posture (no network, only the
recorded permissions, alias-first, local-only), and the protected-data boundary. See `README.md` for
the feature surface and build.

This repository is the standalone home of the app.
